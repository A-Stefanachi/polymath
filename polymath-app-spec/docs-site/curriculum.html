Summary

  • Skills form a directed acyclic graph with explicit prerequisite edges.
  • Tiers L0–L3 describe depth; the product targets tier L1 working knowledge per subject.
  • stub nodes reserve future map space and are neither taught nor used as prerequisites for active skills.
  • The project ladder supplies bench evidence; level L5 (KiCad board) is specified but scheduled late in delivery.

Competence tiers

L0
Recognition and guided execution.
L1
Working knowledge: guided projects, debugging, unaided checkpoints.
L2
Deeper design and trade-off reasoning (future spine).
L3
Expert breadth; aspirational, not a version 1 commitment.

Initial delivery slice

  • Mathematics essentials
  • Electronics (DC, passives, elementary circuits)

Version 1 ships the first walk only; stub nodes reserve future map space. After first-walk L1, tracks in the capability spine extend the same loop to power, control, mechanical design, UAV integration, cloud twin, and governance.

Project ladder (foundation)

  1. L0 — Blink LED (included in lean slice as manual evidence).
  2. Voltage divider / RC filter correlated with simulation.
  3. Transistor switch and regulator.
  4. I2C sensor with UART logging.
  5. State machine with interrupt service.
  6. L5 — First KiCad PCB (ERC/DRC verification; milestone M5).

Confusable skill sets

Skills that learners commonly conflate (for example, series versus parallel reasoning) are grouped for interleaved practice. Sets are declared in the graph data, not assigned ad hoc at runtime.
