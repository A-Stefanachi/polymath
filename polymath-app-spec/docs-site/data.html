Data model overview

docs/04-data-model.md, schemas/schema.sql

Summary

  • All learner-owned rows are scoped by user_id and protected with row-level security.
  • Stable string keys identify curriculum objects; UUIDs identify runtime rows.
  • attempts, review_log, and skill_state record the learning history.
  • The jobs table implements asynchronous grading; events supports analytics without third-party trackers.

Table groups

Identity and preferences

profiles, consents, reminder preferences, weekly minute targets.

Curriculum

modules, skills, skill_edges, item_templates, items.

Learning loop

sessions, session_tasks, attempts, skill_state, review_log.

Projects

projects, project_steps, user_projects, project_evidence, project_grants.

Tutor and experiments

tutor_threads, tutor_messages, experiment assignment tables (doc 11).

Operations

jobs, events, push subscriptions, privacy requests, item reports.

Notable JSON fields

attempts.grade
Status, score, correctness flag, grader list.
items.rendered
Presentation payload including mathematical alternative text.
items.verification_report
Required when item status is verified.
project_evidence.verification
Automated check results and review metadata.
