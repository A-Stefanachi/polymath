Summary

  • Today — duration and context selection (phone, desktop, bench), then session assembly.
  • Session runner — confidence captured before feedback; no streak-based gamification.
  • iOS — installable PWA via Safari; micro sessions and offline cache are primary phone workflows.
  • Bench context — project steps and evidence capture; task kinds filtered by context.

Primary screens (S01–S20)

Today

Due reviews, weekly minute progress, optional checkpoint notice.

Session

Single-task focus, KaTeX with alternative text, mobile layout constraints.

Map and progress

Frontier rationale; next competence artifact.

Projects

Step checklist, evidence upload, verification status.

Review inbox

FSRS due queue; optional five-minute reviews-only path.

Settings

Reminders, offline storage, privacy controls (export in later milestones).

iOS support

Supported

  • Installation to home screen (Safari → Add to Home Screen)
  • Micro sessions, skill map, due list, progress views
  • Offline cached numeric and multiple-choice items (provisional until sync)
  • Camera and file upload for project evidence
  • Minimum 16 px input typography to prevent focus zoom

Platform constraints

  • Web Push requires home-screen installation (iOS 16.4+); verify on device (OA-7).
  • Background Sync is unavailable; synchronization runs on foreground and online events.
  • Extended disuse may evict site storage; outbox flush on visibility change mitigates loss.
  • Code submission, SPICE, and extended tutor sessions target desktop or bench context.

Offline behaviour

When offline, the client displays a persistent banner and stores attempts locally. The server grade is authoritative on reconciliation; mismatches are logged and surfaced to the learner.

Accessibility

Target conformance: WCAG 2.2 Level AA on core flows; automated axe checks in Playwright; manual VoiceOver review before beta.
