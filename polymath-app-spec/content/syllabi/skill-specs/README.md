# Skill specifications, T1 to T6

One YAML file per pillar holds each skill's objective, core ideas, misconceptions, worked example, unaided check and sources.

- **Status:** every skill here is `needs_human_review` in `content/mvp-skill-graph.yaml`. None is `verified`. Doc 05 forbids an LLM from setting that, so a person reviews each one first.
- **Metadata:** the graph wins for `task_kinds`, `grader_types`, `phone_suitable` and prerequisites. Validator rules added fields there that these files may not show.
- **Serving:** nothing here is served. A skill needs verified templates first.
- **Sources:** entries marked UNCERTAIN, (snippet) or (unofficial mirror) need checking before use.
